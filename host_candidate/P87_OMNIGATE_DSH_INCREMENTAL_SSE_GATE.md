P87 DSH/OmniGate streaming parser and UI integration gate. OmniGate v0.10.11 previously showed delayed first assistant content (~10.68s) but streamed later SSE content incrementally; DSH UI behavior not verified. This bounded streaming UTF-8 SSE decoder handles CRLF/LF, split multibyte UTF-8, keepalive comments, multiline data, explicit [DONE], and refuses false end-of-stream success. Never stop current generating model or rotate OmniGate original owner/160x socket. Test-only until original DSH network consumer, actual MainActivity UI and tool_result are wired and tested. No keys, source values or cookies logged. Original installed phone and fixed signer remain unchanged.
